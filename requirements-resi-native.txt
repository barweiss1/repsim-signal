# ReSi runtime requirements for a native (non-container) install on a
# SLURM cluster (see docs/resi_cluster.md). Unlike the NGC
# container requirements files, this installs its own torch/torchvision/etc
# stack via pip rather than relying on a pre-baked base image.
#
# Otherwise identical to requirements.txt, with one deliberate swap:
# opencv-python -> opencv-python-headless. Compute/login nodes are often
# headless servers with no display; the GUI-enabled opencv-python wheel
# pulls in Qt/X11 dependencies that are unnecessary there and that the
# container build already avoids for the same reason
# (see build_resi_enroot_container.sh). Pair with
# constraints-resi-native.txt to reproduce the same known-working version
# matrix as the NGC container.
